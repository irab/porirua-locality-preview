Human Services Directory Examples

What works elsewhere — and what Porirua can learn

Reference deck for stakeholders & project team · July 2026

Why look at other directories?

Before building the Porirua Services Directory, it helps to see what already works elsewhere.

Good directories share common traits:

  • Plain language — “I need food”, not bureaucratic codes
  • Location-first — show what is near the person
  • Trust — accurate phone numbers, reviewed listings
  • Mobile-friendly — most people search on a phone
  • Two audiences — people seeking help, and staff who connect others to services
This deck covers six examples — live directories, community maps, and one ready-made toolkit.
Australia · Live directory

Ask Izzy

askizzy.org.au · about.askizzy.org.au

Free, anonymous mobile website connecting people with health and welfare services across Australia.

CoverageNational — ~450,000 services
How people start“What do you need help with?” — simple categories
Who updates itDedicated team of 15+ staff keeping listings current
Special featureFree to use on mobile without eating into data allowance (some networks)

What works well

  • Categories for people in crisis
  • Separate provider resources site
  • Co-designed with lived experience

For Porirua

Best layout to copy — simple categories and easy to use on a phone. We cannot match their national budget or staffing.
US & Canada · Helpline + directory

211

211.org (US) · 211.ca (Canada)

Free, confidential helpline and web directory for local community services.

Coverage~1.7M programs (US); nationwide in Canada
How people startDial 2-1-1, chat, text, or website
How many people use it19 million+ connections to help per year (US, 2025)

What works well

  • Human + digital — talk to a navigator
  • More than one need at a time — e.g. food and housing together
  • 180+ languages (US)

For Porirua

Shows how powerful it is when someone can talk to a trained person — and why our directory still needs clear categories and Porirua-focused results.
Aotearoa · Government directory

Family Services Directory

familyservices.govt.nz/directory

The government’s official online list of social service providers across New Zealand.

CoverageNational — several thousand organisations
How people use itSearch by keyword, type of help, and region
Who keeps it currentMinistry of Social Development
Can others reuse it?Yes — the government publishes the list for community projects to use
For Porirua: Our main source of service listings — updated automatically each week. We still need to filter to Porirua and check entries locally. The website design is not what we are copying.
United Kingdom · Local router

Sorted Local Help

sorteduk.uk/local-help

Enter a postcode → unlock local council funds, food banks, warm hubs, legal aid.

Coverage317 councils, 2,800+ food banks
DataAggregates council, Trussell Trust, Turn2us sources
For Porirua: “One lookup, many local results” — adapted as suburb search or “near me”.
Aotearoa · Community map

Kore Hiakai — Community Food Map

zerohunger.org.nz/find-a-community-food-organisation

National map of food banks, social supermarkets, community meals, and free stores.

What works well

  • Community-owned narrative
  • Dignity-focused language (social supermarkets vs food banks)
  • Honest: “comprehensive, not exhaustive”

For Porirua

Local trust model. Te Umu ki Rangituhi & Pātaka Kai fit this ecosystem. Works alongside the government directory — does not replace it.
England · Specialist directory

Homeless England

homeless.org.uk/homeless-england

~1,500 homelessness projects — hostels, outreach, day centres, Housing First.

What works well

  • Detailed search options focused on housing only
  • Sector-maintained — practitioners trust it

For Porirua

Specialist directory done well — useful if Porirua later adds housing-focused views.
Free toolkit · Not a live website

ORServices

sarapis.org/human-services/orservices

A free, ready-made directory package — public search website and editing tools in one. Built for communities that want their own directory without buying expensive software.

What it isA toolkit you install and run — not an existing national directory
Who it suitsCouncils, nonprofits, and community groups overseas (especially North America)
CostFree software — you pay for hosting and setup

ORServices — what it offers Porirua

Strengths

  • Public search website and map — works on phones
  • Built-in editing area for staff to update listings
  • Import and export lists (spreadsheet-friendly)
  • Different staff can edit different organisations
  • Custom colours, logo, and printable lists

Trade-offs

  • Needs ongoing web hosting and technical upkeep
  • Still needs custom work to connect NZ government data and local lists
  • Smaller user community than mainstream website builders

For Porirua

Alternative approach if we want one off-the-shelf product instead of building separate public site and admin tools.

Best when we have technical support for hosting and are happy to adapt an overseas-designed tool.

Our current plan may be simpler for the budget and local team.

Three ways we could build Porirua’s directory

Option A — Current plan
Combine government list + Connections Map in one database. Staff use an editing website to review and publish. Public get a simple search site and map.

Option B — Use ORServices toolkit
Import our data into the free ORServices package — public site and editing tools come together. Needs technical hosting support.

Option C — Mix and match
Use a ready-made system for data and editing, but build a custom Porirua-branded public website for the best user experience.

We are planning Option A — best fit for budget, long-term stability, and how the Porirua Locality team will work. Option B (ORServices) stays on the table if we prefer one off-the-shelf product.

Summary

  • Big directories (Ask Izzy, 211, Family Services Directory) — show how to design for the public and keep listings accurate
  • Community maps (Kore Hiakai, Connections Map) — local trust matters more than generic lists
  • ORServices — main free toolkit if we want public site + editing tools in one package
  • Porirua’s directory combines the best of these — simple categories, government data, and local community knowledge
